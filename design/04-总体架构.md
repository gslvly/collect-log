## 4. 总体架构

```text
业务前端
  │
  │ signed envelope（projectId + HMAC 签名 + 一行数据）
  ▼
Node.js API
  ├── 签名校验（时间窗 + nonce）
  ├── 表 ID 解析
  ├── 内存元数据缓存
  ├── 字段白名单与类型校验
  ├── 上传限流
  └── 参数化 INSERT（完整列集合）
  │
  ▼
ClickHouse
  └── data.collect_<internal_id>        # 采集数据

SQLite（$DATA_DIR/sqlite3/app.db）
  ├── app_users                          # 后台账户
  ├── collect_tables                     # 采集表元数据
  └── collect_fields                     # 字段定义

Vue 管理后台
  │
  ▼
Node.js 管理与查询 API
  ├── 账户管理
  ├── 数据表与字段管理
  ├── 数据查询构造器
  └── 统计查询
```

管理后台和业务前端均不能直接连接 ClickHouse 或 SQLite。
